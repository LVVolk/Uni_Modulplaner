# Uni Modulpaner

Deutsch:
Eine einfache Webanwendung um meinen Studienverlaufsplan (SVP) plastisch machen, und um die tatsächlichen Module erweitern, um mein Studium individuell planen, ECTS und den Notendurschnitt berechnen zu können.

English:
A simple Webapplication to make my study plan malleable and be able to append the actual modules, plan my own studies and calculate ECTS as well as my average grade.

Using React + Vite + Tailwind
